Webhooks

Register an https endpoint and the events it wants; Truebex posts each event as JSON, signed with the endpoint's secret. Manage endpoints with a webhooks:manage key or on Dashboard → Webhooks.

Verify every delivery

Signatures follow the Standard Webhooks specification, so its libraries work as they are. The signed content is webhook-id, webhook-timestamp and the raw body joined by dots; refuse a timestamp more than 5 minutes off.

POST /your/endpoint
content-type: application/json
webhook-id: msg_0199c6…
webhook-timestamp: 1791763200
webhook-signature: v1,K5oZfzN95Z9UVu1EsfQmfVNQhnkZ2pj9o9NDN/H/pI4=

{"type":"share.published","timestamp":"2026-10-11T09:00:00Z","data":{…}}

Python

import os, truebex

event = truebex.verify_webhook(
    os.environ["TRUEBEX_WEBHOOK_SECRET"], request.headers, request.body
)
print(event["type"], event["data"])

JavaScript

import { verifyWebhook } from "@truebex/sdk/webhooks";

const event = await verifyWebhook(process.env.TRUEBEX_WEBHOOK_SECRET, req.headers, rawBody);

Events

data is the resource as the API itself shapes it. project.ops_appended is sent once per 30 s per project, with the first and last sequence numbers.

EventWhen
project.ops_appendedOperations were accepted (one event per 30 s per project: first and last numbers, authors).
project.version_createdA version was named.
project.member_addedSomeone was invited to a project.
job.succeededA render job of the account succeeded.
job.failedA render job of the account failed.
share.publishedA share went live.
share.visits_dailyYesterday's visits to the account's shares (00:10 UTC).
market.order.updatedAn order or request for quote of the account changed state.
market.feed.completedA catalogue feed run of the account's supplier ended.

Retries

A 2xx answer within 15 s is a success. Anything else is retried after these waits, each with ±10 % jitter. An endpoint failing for 5 days is switched off and its account is e-mailed; deliveries are kept 30 days.

Testing locally

Endpoints must be https and resolve to public addresses. For a local receiver, run the API with WEBHOOKS_ALLOW_HTTP_LOCAL=true and register http://127.0.0.1:<port>/.
