Developers

The Truebex API

Work with Truebex from your own code over HTTPS. Create a key with the scopes it needs, call the API with it, and hear about changes through signed webhooks. Every plan includes a monthly request allowance.

Get an API keyView usage

Quick start

  1. Create a free account (Google or email).
  2. Open Dashboard → API keys, tick the scopes you need and create a key. Copy it: it is shown once.
  3. Call the API:
curl https://api.truebex.com/v1/ping \
  -H "Authorization: Bearer tbx_live_your_key"

What the API covers

  • Projects over the API — A project is its history: operations in server order, snapshots of the full model and named versions.
  • Jobs and exports over the API — A job names a project and a sequence number and answers an estimate in cost units.
  • Share links over the API — A share is a bundle of panoramas, renders and the sheet PDF behind one link.
  • The marketplace over the API — The catalogue answers without a key; a key with market:read lifts the anonymous limit and is metered like any call.
  • Webhooks — Register an https endpoint and the events it wants; Truebex posts each event as JSON, signed with the endpoint's secret.
  • SDKs for Python and JavaScript — Both SDKs are generated from the same description as this reference, so every operation is a typed method.
  • The Truebex MCP server — Your AI app starts the server on your computer and talks to it over stdio.

Authentication

Send your key on every request, either as a bearer token or in the X-API-Key header. Keys start with tbx_live_.

Authorization: Bearer tbx_live_…
# or
X-API-Key: tbx_live_…
  • Keep keys on your server. Never ship them in browser or app code.
  • Use one key per environment, with only the scopes it needs, and revoke a key the moment it leaks.
  • We store only a hash of each key, so a lost key cannot be recovered: create a new one.

Scopes

Choose a key's scopes when you create it. A call without the scope it needs answers 403 forbidden, naming the scope in data.needed. Keys made before scopes existed keep every read scope.

ScopeLets the key
projects:readread scopeOpen projects and read their operations, snapshots, versions, members, presence and jobs.
projects:writeCreate and rename projects, push operations, register snapshots, name and restore versions, invite.
jobs:writeSubmit and cancel render jobs, the presentation pack among them.
shares:writeUpload bundles and publish, list, change and revoke shares.
market:readread scopeRead the catalogue with the key's limits instead of the anonymous ones.
supplier:feedSend a supplier's catalogue feed and read its import reports.
webhooks:manageRegister webhook endpoints, read deliveries, re-send them and rotate secrets.

Base URL

https://api.truebex.com

Usage and limits

Every call with a key counts toward your monthly allowance, across all your keys. Allowances reset on the 1st of each month (UTC). Each response carries your current numbers:

X-RateLimit-Limit: 1000
X-RateLimit-Remaining: 958
PlanRequests / monthActive keys
Free1,0002
Pro100,00020
Team100,00020
Enterprise5,000,000200

Each key also has a burst limit of 60 calls at once, refilled at 600 a minute. Past it the API answers 429 rate_limited with retry_after_s, before the monthly allowance is touched.

Errors

Every error has one shape. Show detail to people; branch on code. request_id identifies the call if you write to us.

HTTP/1.1 403 Forbidden
{
  "detail": "This API key does not have the projects:write scope.",
  "code": "forbidden",
  "status": 403,
  "request_id": "5c1e0f…",
  "retry_after_s": null,
  "data": { "needed": "projects:write", "scopes": ["projects:read"] }
}
StatusCodeMeaning
400contract_versionThe X-Truebex-Contract major version is not served.
401unauthenticatedMissing, malformed, invalid or revoked API key.
403forbiddenThe key lacks a scope (data.needed) or the account's role is too low.
404not_foundUnknown, or not visible to the key's account.
422validation_failedA field failed its rule (data.fields).
429rate_limitedThe burst limit or the monthly allowance is reached (retry_after_s).
5xxinternal_errorOur side. Retry with backoff: 1, 2, 4 … 60 s.

Versions

Each route group speaks a versioned contract, sent and echoed as X-Truebex-Contract (for example project-log/1.2). Additions never break a version; the SDKs send it for you.
