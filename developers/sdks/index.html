Developers

SDKs for Python and JavaScript

Both SDKs are generated from the same description as this reference, so every operation is a typed method. Writes that take an idempotency key get one, so retries are safe; webhook helpers verify signatures.

Rolling out. The packages are being published to PyPI (truebex) and npm (@truebex/sdk).

Install

pip install truebex          # Python 3.11+, version 1.4.0
npm install @truebex/sdk     # Node 18+, browsers, workers

Python

import truebex

client = truebex.Client()  # reads TRUEBEX_API_KEY
project = client.projects.create(name="House", doc_version=38)
ops = client.projects.pull_ops(project["project_id"], after=0, wait_s=25)

try:
    client.projects.delete(project["project_id"])
except truebex.TruebexError as err:
    print(err.status, err.code)  # 403 session_required

JavaScript

import { Truebex, TruebexError } from "@truebex/sdk";

const truebex = new Truebex(); // reads process.env.TRUEBEX_API_KEY
const project = await truebex.projects.create({ name: "House", doc_version: 38 });
const { ops } = await truebex.projects.pullOps(project.project_id, { after: 0, wait_s: 25 });
