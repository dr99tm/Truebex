What is Truebex?

A building design tool where what you draw is what you see — in real light, at real scale.

Truebex is a Revit-style CAD tool — walls, rooms, openings, dimensions — built inside a real-time engine. The plan you draw and the building you see are one model, so there is nothing to export, nothing to re-render, and nothing to fall out of sync.

It is not a rendering tool bolted onto a modeller. Geometry is exact, areas are live, and the light in the room is computed from the sun, the sky and the openings you placed.

Draw walls, rooms, doors, windows, slabs and stairs in plan — the 3D building forms as you draw. Arcs, groups, reference planes and locked dimensions keep your design intent intact.

Real light, in real time

Live areas and dimensions

Frequently asked questions

Short answers about Truebex, hardware, the API and billing.

What is Truebex?

+

Truebex is a desktop building design tool that works in 2D plan and 3D at once. It runs on Unreal Engine 5.7, so the model you draw is lit with real-time global illumination and can be walked through in first person while you design.

Is Truebex a Revit alternative?

+

Truebex works the way architects expect from BIM tools — walls, rooms, openings, dimensions and reference planes — but it is its own application, not a Revit plug-in. Its difference is that design, lighting and walkthrough happen in the same real-time model.

Can I walk through my design?

+

Yes. First-person mode puts you inside the model at eye height with collision, and you can switch to it at any point while designing.

Does Truebex calculate areas?

+

Rooms show their area live and update as walls move. Full quantity take-offs and cost estimates are on the roadmap.

What hardware do I need?

+

A Windows PC with a modern DirectX 12 graphics card. NVIDIA RTX cards also unlock DLSS 4.5 and hardware ray tracing.

Is there an API for developers?

+

Yes. Create API keys in your dashboard and call the Truebex API with a bearer token. Every plan includes a monthly request allowance; see the developer docs.

How can I pay?

+

Professional plans are billed monthly. We are rolling out card payments through Stripe and local payment in Iraq through Wayl (QiCard, FIB and ZainCash).
